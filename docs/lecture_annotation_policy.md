# Internal annotation policy v3

This policy guides existing executable tools; it does not grant filesystem or shell access.

1. Professor speech is the source. Resolve knowledge/evidence by canonical IDs. Preserve exact numbers, signs, symbols and source timing.
2. Mark what is already printed. Write only genuinely additional teaching; keep long explanations in Detailed Notes. A mark has no redundant text card.
3. Select only supplied canonical IDs associated with the knowledge's PDF blocks. Never invent coordinates, silently pick the nearest object, or turn a rejected/ambiguous glyph into a fact.
4. Prefer small, complementary actions: term underline, result box, symbol circle if safe, explicit term relations, short supported notes. More actions are not a quality score.
5. Figure blocks are not recognized points/vectors. Pixel candidates remain uncertain until supported visual confirmation; no giant figure circle fallback.
6. Read and inspect before writing. All writes validate registry/source fingerprints and provenance. Duplicate calls are idempotent. Unsupported tool/target/text requests fail explicitly.
7. Execute deterministic collision-checked layout. Do not cover native content. A suppressed mark remains observable as unplaced; source knowledge is never deleted for space.
8. Review actual rendered pages, not JSON validity alone. Edit only supplied action IDs through remove/replace/retarget/shorten/move/reroute. At most two mutation rounds. Unsafe edits roll back.
9. Model reviews are fallible. Keep stage failures, rejected edits, unresolved ambiguity, and unrendered actions in reports. Human target accuracy and semantic coverage remain unmeasured without gold labels.
10. Keep old jobs, source PDFs/audio, environments, keys and model cache intact. Use legacy/last validated fallback with an observable reason when providers fail.
